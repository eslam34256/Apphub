# 🎨 ملاحظة Rebrand v33 (٢٣ سب ٢٠٢٦)

## الـ Pipeline المستخدم (الفنّي)
1. الصورة الأصلية (1774×887 أبيض) → `logo.png` بإزالة خلفية flood-fill من الزوايا (thresh 55) مع الحفاظ على أسهم العلامة البيضاء المحاصرة
2. قص علامة الأيقونة عبر كشف فجوة البياض بين العلامة وكلمة "Apphub" (column density على الـ RGB)
3. trim tight (threshold 212 لقتل ضوضاء anti-alias) → `logo-mark.png` (٨٪ padding مربع)
4. أيقونات المتاجر/الـ PWA = العلامة فوق كريم البراند #faf8f5 بالمقاسات: 192 · 512 · maskable 512 (٢٣٪ padding للدائري) · apple 180 · favicon 64
5. Service worker bumped `v1 → v2` لإجبار كاشات المستخدمين القديمة على جلب الأيقونات الجديدة
