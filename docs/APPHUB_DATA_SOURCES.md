# 🧾 APPHUB_DATA_SOURCES — مصادر الداتا ومستوى الثقة

**القاعدة الذهبية:** كل رقم معروض لازم يكون ليه مصدر + تاريخ مراجعة، أو متوسوم صراحة «استرشادي/تحريري». ممنوع اختلاق مشاهدات تاريخية.

| الداتا | المصدر | الثقة | التحديث | الوسم في الواجهة |
|---|---|---|---|---|
| أسعار UC ببجي | Midasbuy الرسمي (الشريك الرسمي لببجي) — مراجعة يدوية موثقة | عالية | `UC_REVIEW_DATE` سبتمبر 2026 | «المراجعة: سبتمبر ٢٠٢٦ · المصدر: Midasbuy» |
| متوسطات سوق الشدات | رصد يدوي لقنوات بيع | **استرشادي** | نفس التاريخ | «متوسط سوق استرشادي — مش عرض بيع» |
| باقات الإنترنت (فودافون/WE/أورنج) | قوائم الأسعار الرسمية المعلنة | عالية | `telecom-data.ts` بتاريخ مراجعة | تاريخ معلن في الرادار |
| اشتراكات AI | الأسعار الرسمية العالمية USD (٥ مصادر متقاطعة يونيو–سبتمبر 2026) + تحويل لايف بسعر صرف حقيقي (/api/fx) | عالية للدولار / لايف للجنيه | `AI_REVIEW_DATE` | «تحويل لايف بسعر صرف حقيقي» |

| تطبيقات/فئات/دول | قاعدة بيانات المشروع (167+/16/3) | مؤكدة | مستمر | الأرقام محسوبة live مش مكتوبة |
| العروض deals | ستاتيك تجريبي موسوم + DB (deals) — المنتهي بيترشح أوتوماتيك | مختلطة | أدمن | «بيانات تجريبية» موثق في الكود + تقرير عروض بايظة |

| fx سعر الصرف | مصدر خارجي لايف مع fallback آمن | عالية | لحظي | معروض كمصدر |

## تمثيلات مطلوبة ومحترمة
- سعر غير معروف = غائب/موسوم، مش صفر (getMonthlyPrice بيرجع 0 فقط للمجاني الحقيقي الموثق)
- مفيش سلاسل تاريخية مخترعة — الرادارات بتعرض نقاط مراجعة معلنة فقط
- كل import لداتا فيه تعليق مصدر في رأس الملف (uc-data / telecom-data / ai-radar-data)
