## ⚠️ فجوتان مُقبولتان بتوثيق (قرار مؤسس)
### 1. `next` CRITICAL — DoS في Image Optimizer
- **الحقيقة:** الثغرة خاصة **التشغيل المستضاف ذاتيًا (self-hosting)** واستغلالها بيقصّ على سيرفرك — Vercel (حفّظنا عليه) **يتعامل مع Image Optimization منفصلًا** ولا يعرّض العملية لهذا السطح.
- **الإجراء:** بقينا على 14.2.35 (أحدث patch لخط 14 بدون تكسير) — ترقية major لـ Next 16 مخططة بعد الإطلاق (مع تثبيت React).
- **معيار الخروج:** لو قررنا self-host بأي وقت، الترقية شرط مسبق **قبل** أي deploy.

### 2. `postcss` HIGH — XSS عبر `</style>` في Stringify الداخلي
- **الحقيقة:** PostCSS بيعالج **CSS مش كتابته** — سطح الاستغلال ده محتاج حقن CSS داخل ستايلات المشروع وقت البناء، مش دخل مستخدم. مخاطر وقت-بناء فقط (الخوارزمية نفسها نظيفة في مخرجات production).
- **الإجراء:** متمثلين في منصات البناء الموثوقة (Vercel) + نراقب الترقية مع Next 16.
